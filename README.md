# Skyrim AI Pack (I&A Safe)

Modular AI dialogue, voice pack, automation, and mod compatibility system for large immersive/adult Skyrim modlists.

## Structure Overview

- `/docs/` — Reference docs, flowcharts, install guides
- `/mantella/` — Mantella profiles and prompts
- `/chim/` — CHIM profiles and templates
- `/min_ai/` — Min AI configs
- `/herika/` — Herika mod assets and integration notes
- `/voices/` — All AI voice pack folders
- `/scripts/` — Install, backup, and utility scripts
- `/config/` — Modlist references, settings, and mappings

## Quick Start

1. Clone repo
2. Populate `/voices/`, `/mantella/`, `/chim/`, etc. as needed
3. Run `/scripts/install_skyrim_ai_pack.ps1`
4. Review `/docs/` for visual guides, troubleshooting, and workflow tips

For additions (CHIM, Min AI, Herika), repeat seed/config/test steps as new features are rolled out.
